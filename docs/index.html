Do not invent causality.

Parent links express recorded hierarchy/context. They do not prove finish-to-start dependencies. A sum along a parent path double-counts nested/overlapping durations and is not a causal critical path, self time or execution makespan.

Parent/child time relations

A child starting before or ending after its parent is exposed, not silently repaired or automatically rejected. Async work, clock disagreement or instrumentation can explain it; the trace alone cannot decide.

06 / WHAT THE RECORD CANNOT PROVE
Exact arithmetic.
Limited knowledge.
The interval union is recorded coverage, not measured CPU busy time. The uncovered part of a recorded span is not proof the agent was idle. Peak overlapping spans is not resource utilization. Overlap excess is repeated duration accounting, not wasted work. Clock skew and missing instrumentation can change every timing interpretation.
The native CLI now rejects nonfinite numeric values, duplicate JSON keys and invalid parent cycles, handles mixed timestamps and deep graphs iteratively, and fails its JSON status on parser/graph issues. Original gate choices remain separate from this inspector. Zero-baseline percentage change is undefined, not Infinity JSON.
All 33 original tests, fixed trace fixtures and demo remain byte-preserved. The original analysis and HTML report are retained. Original timing/cost values are fixtures, not a real model run. This inspector does not contact a model, rescore output, predict latency or diagnose bottlenecks.
